# 数学与方法准备：AI 在弹性求解中改变什么

本稿服务于本科弹性力学讨论课。正文讲述应精简；这里保留组员核对所需的推导。基本场关系结合本机课程笔记与 [Bower 的作者教材](https://solidmechanics.org/Text/Chapter3_2/Chapter3_2.php)；算法依据和阅读状态见 [阅读表](reading-list.md)。下面的轴向杆推导与实验设计为本项目自行构造，未冒称复现某篇论文。

## 1. 从物理问题到边值问题

背景可用一句话概括：从弹性经验关系，到应力 / 应变的连续体场描述，再到解析与数值边值求解，研究对象始终是给定条件下的位移、应变、应力及其可靠性。10 分钟汇报不展开人物年表。

限定 **静力、小变形、无初应力、均匀各向同性线弹性**。在区域 \(\Omega\) 内，未知位移 \(\mathbf u\)、应变 \(\boldsymbol\varepsilon\) 和应力 \(\boldsymbol\sigma\) 满足：

\[
\underbrace{\nabla\!\cdot\boldsymbol\sigma+\mathbf b=\mathbf0}_{\text{平衡}},\qquad
\underbrace{\boldsymbol\varepsilon=\tfrac12(\nabla\mathbf u+\nabla\mathbf u^T)}_{\text{几何}},\qquad
\underbrace{\boldsymbol\sigma=\lambda\operatorname{tr}(\boldsymbol\varepsilon)\mathbf I+2\mu\boldsymbol\varepsilon}_{\text{本构}}.
\]

\(\mathbf b\) 是单位体积体力（N/m³）；\(\lambda,\mu\) 为 Lamé 常数（Pa）。应力、应变均为对称张量。对于三维各向同性材料，

\[
\mu=\frac{E}{2(1+\nu)},\qquad
\lambda=\frac{E\nu}{(1+\nu)(1-2\nu)}.
\]

稳定的常规各向同性线弹性取 \(E>0,-1<\nu<1/2\)。端点为极限，不能直接带入上述有限常数公式。

边界条件同样属于问题定义：

\[
\mathbf u=\bar{\mathbf u}\text{ on }\Gamma_u,\qquad
\boldsymbol\sigma\mathbf n=\bar{\mathbf t}\text{ on }\Gamma_t.
\]

\(\Gamma_u\cup\Gamma_t=\partial\Omega\)，两类边界在通常的分块处理下不重叠；约束需消除刚体运动。纯面力问题还要满足整体力 / 力矩平衡，位移只能确定到刚体运动。动态问题出现惯性项，有限变形的应变及应力测度也会改变。

**“不变”是同一个问题设定下必须满足的关系。** 如果 AI 学本构，\(\lambda,\mu\) 公式并非先验固定，需要另加材料对称性、能量与稳定性要求；这与本稿已知本构的求解任务不同。

## 2. AI 可以进入哪些步骤

传统工作流：明确工程目的 → 简化几何 / 物理假设 → 定义材料、载荷、边界 → 选择解析或离散方法 → 求解 → 检查误差与适用性 → 用于判断。

| 介入方式 | 网络主要学什么 | 典型输入 → 输出 | 主要信息 | 本轮判断 |
| --- | --- | --- | --- | --- |
| 监督代理模型 | 有限维参数与响应之间的映射 | 几何 / 材料 / 载荷参数 → 位移、应力或指标 | 实验或数值解标签 | 多次查询可能有价值，先算数据生成与训练成本 |
| 单实例 PINN | 一个给定边值问题的解函数 | 空间坐标 → 位移等场变量 | 方程、边界，可选观测 | 适合解释物理约束如何进入训练；新问题通常需再训练 |
| 能量方法 DEM | 使合适能量泛函较小的位移函数 | 坐标 → 位移 | 变分原理、边界、积分 | 与 PINN 同为学习函数，但训练目标不同；不展开第二套推导 |
| 神经算子 | 一族问题的输入函数到解函数的映射 | 载荷 / 系数场 → 解场 | 多实例数据或物理约束 | 面向重复求解；迁移到不同分布与几何仍需验证 |
| 本构学习 | 材料应力响应或能量函数 | 应变 / 状态变量 → 应力 / 能量 | 材料试验与物理先验 | 改的是材料描述，不能混成“已知本构的场求解” |

PINN、代理和算子并非互斥标签，参数化 PINN 也可做代理。先说学的对象，再说算法名称。[PINN 原始工作](https://arxiv.org/abs/1711.10561)、[DEM 论文](https://www.sciencedirect.com/science/article/abs/pii/S0045782519306826)、[FNO](https://arxiv.org/abs/2010.08895) 与 [DeepONet](https://arxiv.org/abs/1910.03193) 支持这些机制区别，不能由此直接断言哪种对所有弹性任务最好。

## 3. 神经网络到底是什么模型

最小多层网络写成

\[
\mathbf h^{(0)}=\mathbf x,\quad
\mathbf h^{(k+1)}=\tanh(W_k\mathbf h^{(k)}+\mathbf c_k),\quad
N_\theta(\mathbf x)=W_o\mathbf h^{(K)}+c_o.
\]

\(\theta\) 收集所有权重与偏置。它是一个可调的函数族：改变 \(\theta\)，曲线或空间场随之变化。非线性激活让表示能力超出线性映射；但 **表示线性弹性解的网络可以是非线性的，被求解的方程仍然是线性方程**。

训练通过减小损失选择参数。自动微分按链式法则对这个函数求导，不是自动解 PDE，也不是有限差分。通用逼近能力并不保证给定优化过程能找到正确函数，更不自动保证分布外泛化。[DeepONet 的作者明确区分逼近、优化与泛化误差](https://arxiv.org/abs/1910.03193)。

强形式位移 PINN 需要二阶导数，因此本演示使用平滑的 \(\tanh\)。普通 ReLU 网络分段线性，二阶导数在几乎处处为零，不能不加处理地用于这里的二阶强形式残差；这不表示 ReLU 在弱形式或其他任务中普遍无效。

## 4. 主算例：两端固定的轴向弹性杆

这是三维连续体在细长杆、横截面平均与轴向响应假设下的一维教学模型。它不包含泊松侧向变形、二维应力集中或裂纹。

杆长 \(L\)，面积 \(A\)，弹性模量 \(E\)，轴向分布荷载 \(q(x)\) 单位 **N/m**，轴向位移 \(u(x)\) 单位 m。与三维体力 \(\mathbf b\) 的单位区分。

\[
\varepsilon=u',\quad \sigma=E\varepsilon,\quad N=A\sigma=EAu',\quad N'+q=0,
\qquad u(0)=u(L)=0.
\]

当 \(E,A\) 为常数且 \(q(x)=q_0\sin(\pi x/L)\) 时，

\[
EAu''+q_0\sin(\pi x/L)=0.
\]

令 \(\xi=x/L\)，\(u_0=q_0L^2/(EA)\)，\(U=u/u_0\)，得到无量纲问题：

\[
U''(\xi)+\sin(\pi\xi)=0,\quad U(0)=U(1)=0.
\]

这里与下文的撇号均表示对 \(\xi\) 求导。两次积分得

\[
U(\xi)=\frac{\sin(\pi\xi)}{\pi^2}+C_1\xi+C_2.
\]

边界给出 \(C_1=C_2=0\)，故

\[
U_*(\xi)=\frac{\sin(\pi\xi)}{\pi^2},\qquad
U_*'(\xi)=\frac{\cos(\pi\xi)}\pi.
\]

可选量纲示例：\(L=1\,\mathrm m,E=200\,\mathrm{GPa},A=10^{-4}\,\mathrm{m}^2,q_0=10^3\,\mathrm{N/m}\)。则 \(u_0=50\,\mu\mathrm m\)，最大位移约 \(5.066\,\mu\mathrm m\)，最大轴向应力绝对值约 \(3.183\,\mathrm{MPa}\)。这些是本模型的解析结果，不是工程试验测量。

## 5. 把这个问题变成 PINN

采用硬位移边界的试函数：

\[
U_\theta(\xi)=\xi(1-\xi)N_\theta(\xi).
\]

无论参数取什么值，端点都为零。展开二阶导数，令 \(g=\xi(1-\xi)\)：

\[
U_\theta''=-2N_\theta+2(1-2\xi)N_\theta'+\xi(1-\xi)N_\theta''.
\]

在内部配点 \(\xi_i\) 上计算残差及损失：

\[
r_\theta(\xi)=U_\theta''(\xi)+\sin(\pi\xi),\qquad
\mathcal L_r=\frac1{n_r}\sum_{i=1}^{n_r}r_\theta(\xi_i)^2.
\]

参数更新为 \(\theta\leftarrow\theta-\eta\nabla_\theta\mathcal L_r\) 的优化步骤（本演示实际使用 Adam）。**训练没有使用解析位移标签。** 仍然使用了精确的材料、载荷、边界与方程信息。

若使用直接输出 \(\widetilde U_\theta=N_\theta\)，一般还需软边界损失

\[
\mathcal L= w_r\mathcal L_r+w_b[\widetilde U_\theta(0)^2+\widetilde U_\theta(1)^2].
\]

软惩罚不严格保证边界成立，权重和量纲会影响训练。本演示的硬边界消除了这项权衡；**不能用本演示来证明所有 PINN 的边界处理都容易**。多个损失项梯度失衡是已研究的训练困难。[Wang、Teng 与 Perdikaris 的论文](https://arxiv.org/abs/2001.04536)

训练流程只需展示五步：坐标 → 网络位移 → 自动微分 → 方程残差 → 更新参数。解析解用于独立核验，不进入损失。

## 6. 从一维桥接二维弹性

在二维区域输入 \((x,y)\)，输出 \((u_x,u_y)\)，通过自动微分得到

\[
\varepsilon_{xx}=u_{x,x},\quad\varepsilon_{yy}=u_{y,y},\quad
\varepsilon_{xy}=\tfrac12(u_{x,y}+u_{y,x}).
\]

必须先确定平面应力还是平面应变。以 **平面应力** 为例，\(\gamma_{xy}=2\varepsilon_{xy}\)，

\[
\begin{bmatrix}\sigma_{xx}\\\sigma_{yy}\\\sigma_{xy}\end{bmatrix}
=\frac{E}{1-\nu^2}
\begin{bmatrix}1&\nu&0\\\nu&1&0\\0&0&(1-\nu)/2\end{bmatrix}
\begin{bmatrix}\varepsilon_{xx}\\\varepsilon_{yy}\\\gamma_{xy}\end{bmatrix}.
\]

代入得到两个平衡残差：

\[
r_x=\sigma_{xx,x}+\sigma_{xy,y}+b_x,\qquad
r_y=\sigma_{xy,x}+\sigma_{yy,y}+b_y.
\]

再处理位移 / 面力边界。位移型 PINN 的应变相容由定义满足；如果同时独立输出位移、应力，则还要加入本构一致性残差。这种混合方式能降低平衡项的导数阶数，但引入更多场与损失耦合。

可用 [Haghighat 等的固体力学研究](https://arxiv.org/html/2003.02751v2) 作为文献桥接：该文采用多个网络、合成参考数据与平衡 / 本构约束，并涉及材料参数识别。**它的训练设定与本项目纯方程、硬边界的一维演示不同。** 汇报不声称已经完成二维数值复现。

## 7. 怎样判断结果可信

三种事情要分开：物理模型是否合理；数值解是否可靠；学习过程或参数是否可解释。写出方程只能说明第一层的一部分。

本演示保留实际训练快照，并在未用于优化的 401 点均匀网格检验：

\[
e_u=\frac{\|U_\theta-U_*\|_2}{\|U_*\|_2},\quad
e_d=\frac{\|U_\theta'-U_*'\|_2}{\|U_*'\|_2},\quad
r_{\mathrm{RMS}}=\sqrt{\frac1n\sum r_\theta^2},\quad
e_b=\max(|U_\theta(0)|,|U_\theta(1)|).
\]

导数误差对应归一化应变 / 应力误差。再报告最大绝对误差和残差峰值，避免均值掩盖局部问题。参考离散法使用 100 个线性杆单元求解同一问题，并将分段线性位移、分段常应变投到相同验证网格比较。只作教学基准，训练耗时与 FEM 求解耗时不构成系统性能评测。

本问题中还可以解释为什么连续残差有用。设 \(e=U_\theta-U_*\)，若同样满足齐次端点、足够光滑，则 \(e''=r\)。分部积分和 Poincaré 不等式给出

\[
\|e'\|_{L^2}^2=-\int_0^1e\,r\,d\xi
\le\|e\|_{L^2}\|r\|_{L^2},\qquad
\|e\|_{L^2}\le\frac1\pi\|e'\|_{L^2},
\]

故 \(\|e'\|_{L^2}\le\|r\|_{L^2}/\pi\)，\(\|e\|_{L^2}\le\|r\|_{L^2}/\pi^2\)。这是一维边值问题的推导，**连续全域残差范数不等于有限训练点的损失**。当前 401 点采样验证也不是严格全域误差证明；该推导不直接推广成任意几何 / 本构问题的保证。

动画展示的是优化迭代，横坐标是空间位置；它不是杆随物理时间振动，曲线的高度也不是杆发生弯曲。

## 8. 适用性、泛化与工程取舍

- **一次简单正问题**：解析法或 FEM 通常更直接。本项目不把 NN 训练包装成效率优势。
- **多次参数查询 / 优化**：代理和算子可能降低在线成本，前提是训练范围、数据质量与验证覆盖足够；总收益需摊销离线成本。
- **测量驱动反问题**：可同时训练场与材料参数，但先查可辨识性。若只知 \(u\)，而 \(q_0,E\) 均未知，本杆方程主要约束 \(q_0/E\)，不能凭训练同时唯一恢复二者。
- **应力集中、材料界面、近不可压缩或复杂边界**：场的尺度、光滑性与条件数发生变化，需要专门处理。光滑位移拟合不能自动保证应力峰值准确。
- **同一实例未见位置**只是空间插值检验；新材料、新载荷函数、新边界和新几何是不同问题。本演示只训练一个载荷，未建立这些变化的泛化证据。

开放讨论问题建议：**“若一个模型位移预测很准，但局部最大应力缺少可靠误差界，你会把它用于课堂演示、设计初筛，还是安全验算？每种用途还要补什么证据？”**

不要求“结果或解释”二选一，要求听众根据用途给证据标准与选择理由。
