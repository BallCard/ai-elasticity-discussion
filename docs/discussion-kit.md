# 小组讨论与分工包

使用目标：把“各找一些资料”变成能融合的证据与问题。首轮建议每人交 **1 页要点 + 1 个原创图示 / 推导 + 2 条可靠来源 + 1 个反例**，无需各自先做整套 PPT。角色尚未指派给具体成员。

## 分工建议

| 工作包 | 要回答的问题 | 最小交付 | 阅读入口 |
| --- | --- | --- | --- |
| A · 力学与流程 | 输入什么，未知什么，解需满足什么？AI 可以插入何处？ | 三类方程 + 边界；传统求解流程图；模型假设清单 | 现有课程笔记；[技术笔记](technical-notes.md) §1–2；阅读表 R1 |
| B · 算法与推导 | NN 如何表示解？PINN 的损失约束了什么？ | 一维算例 5 步推导；二维对应关系；说明所需数据 | 技术笔记 §3–6；R2、R3 |
| C · 工程与反方 | 哪类任务值得用？论文究竟证明到哪一步？ | 1 张方法比较表；1 张论文证据卡；3 个失败情形 | R3、R4、R5；阅读表的证据规则 |
| D · 讲述与动画 | 怎样让听众在 1 分钟内理解训练？什么要删？ | 20–30 秒分镜；一次误差展示；计时提纲 | [动画说明](../demo/README.md)；R8、R9 |
| 组长 · 融合 | 这些内容是否共同回答老师主题？ | 确定主问题、主案例、结论；整合引用；组织彩排 | [PPT 提纲](../slides/outline.md)与下方检验表 |

3 人可合并 C / D；5 人可将 C 分为文献与反方。分工针对内容，主讲人要理解全部主线。所有人都保留提问和修正的责任。

## 第一次组会 · 建议 45 分钟

| 时间 | 活动 | 留下的结果 |
| --- | --- | --- |
| 0–5 分钟 | 组长读老师主题、时间限制与本轮主问题 | 一句话选题；哪些内容暂不讲 |
| 5–15 分钟 | 每个工作包讲 2 分钟，其余时间澄清概念 | 信息缺口、术语误解、证据冲突 |
| 15–25 分钟 | 先独立写想法，再轮流发言，暂缓评价 | 6–10 张想法卡；每张注明场景与待验证猜想 |
| 25–35 分钟 | 交换角色，替其他人的方案找反例 | 可失败的条件、要补的实验或资料 |
| 35–45 分钟 | 按“切题、可讲透、可验证、时间成本”取舍 | 选 1 个主方法 + 1 个算例；负责人及下次检查日期 |

组长可这样开场：“我们要共同回答：在一个明确的弹性边值问题里，AI 改变了哪一步，凭什么相信它的结果，什么时候值得用？每份资料都请围绕这三个问题给证据。”

## 头脑风暴题卡

下列均是研究提问，尚未声称完成。难度只是准备成本判断。

| 想法 | 需要的背景与可检验问题 | 建议处理 |
| --- | --- | --- |
| 让网络直接给位移场 | R2 / R3；坐标输入如何通过求导得到应变与应力？ | 主线候选，已提供教学原型 |
| 用少量位移测量反推弹性模量 | R3；载荷是否已知？参数能否唯一辨识？噪声多大？ | 后续研究候选，先画示意，勿宣称实测成果 |
| 一次训练，扫描大量材料参数 | R3 / R6 / R7；训练集覆盖的材料范围是什么？ | 解释代理模型与算子学习的价值 |
| 借助能量避免直接算二阶导数 | R4；能量泛函是否适用？自然边界如何进入？ | 备份页比较，不再现场推一套算法 |
| 学一个热力学一致的本构关系 | R1 / R4；能量、对称性、稳定性如何限制网络？ | 未来方向，需额外实验与论文支持 |
| 在高残差处增加采样 | R5；比均匀采样少用多少点？会漏掉应力峰值吗？ | 小实验候选，必须用独立验证 |
| AI 与 FEM 分工：先快速筛选，再精细核验 | 代理思路；何时交回传统求解器？总成本多少？ | 有条件的工程判断，不能冒称成熟部署 |
| 用 Airy 应力函数约束二维平衡 | 课程直梁专题；平衡是否能结构性满足？边界是否更难？ | 有基础的组员可探索；本轮不扩主线 |
| 更换激活函数，看应力误差 | R3；二阶强形式残差中 ReLU 的导数意味着什么？ | 适合讨论数值形式；不能拿不适合的配置作公平性能比较 |
| 同样位移曲线，应力却不同 | 应力依赖空间导数；位移误差与应力误差为何不等价？ | 很好的反方问题，优先保留 |
| 换一个载荷形状，看看训练过的网络会怎样 | R2 / R6；模型是否把载荷作为输入？ | 优先保留，防止把单实例 PINN 当通用求解器 |
| 让动画显示错误而非只显示成功 | 已有训练快照；残差、误差、端点哪个先改善？ | 演示讲述方向，优先保留 |

先宽后窄：前 10 分钟可扩展，最后只保留 1 个主案例、1 个论文迁移例子和 1 个开放问题。

## 反方检验：替自己的结论找麻烦

| 常见主张 | 反方追问 | 本轮最低证据 |
| --- | --- | --- |
| “PINN 能替代有限元” | 单次求解是否更省时？调参和训练算入了吗？ | 先说具体任务；本算例不作替代结论 |
| “损失很小，所以正确” | 未参加训练的位置、边界和应力峰值呢？ | 独立网格解析误差、残差、边界误差 |
| “物理约束让网络可解释” | 能解释的是方程、模型假设还是网络参数？ | 分开说明物理一致性、内部解释、数值可靠性 |
| “对很多位置有效，所以泛化很好” | 是同一实例插值，还是新载荷 / 新材料 / 新几何？ | 明确分布变化对象；不要混用 |
| “不用数据” | 方程、材料、几何、载荷和边界是不是先验信息？ | 明说无解标签，仍需要完整问题定义 |
| “黑箱也能在工程中用” | 错误代价有多高？什么情况下拒绝预测？ | 给适用范围、验证阈值与回退办法 |

## 汇总卡模板

每个贡献可以复制以下字段填写：

```text
问题 / 工程场景：
具体模型假设、输入与输出：
AI 改变哪一步：
最关键的一条公式或图：
来源（原文标题、作者、链接、章节 / 图号）：
原文实际做了什么、取得什么结果：
没有证明什么 / 可能失败的条件：
我的推断或新想法（与原文结果分开）：
是否进主线、准备讲多少秒：
负责人及下一步：
```

- **10/27（初定）**：汇报与讨论。

## 切题与精简检验

每张正文页必须至少回答一个问题：什么弹性问题？AI 改变什么？如何检验？什么时候值得用？不回答则移至备份或删除。

验收时逐项勾选：

- [ ] 开头直接提出“AI 与弹性力学求解”的问题，历史不超过 20–30 秒。
- [ ] 有明确几何、载荷、材料假设、边界及目标量。
- [ ] 至少一个完整的“物理关系 → 网络 → 损失 → 验证”闭环。
- [ ] 公式保留必要符号解释，不逐项念损失函数。
- [ ] 论文成果、本人实验与未来猜想明确区分。
- [ ] 包含 AI 的失效情形与传统方法基准。
- [ ] 18 页正文讲完不超过 600 秒，动画计入总时间。
- [ ] 开放问题 1 个，听众可基于已讲内容参与，讨论不超过约 3 分钟。
