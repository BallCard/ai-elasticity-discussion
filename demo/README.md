## 实验是怎样做的

本例为两端固定、轴向正弦分布荷载的均匀线弹性杆。模型假设、量纲与完整推导见 [数学准备](../docs/technical-notes.md) §4–7。

- 方程：\(U''+\sin(\pi\xi)=0\)，端点 \(U(0)=U(1)=0\)。
- 硬边界：\(U_\theta=\xi(1-\xi)N_\theta\)。
- 网络：1→16→16→1，两层 tanh，321 个参数。
- 训练：64 个随机内部点，Adam，学习率 0.002，3000 次更新，float64，CPU，随机种子 42。
- **没有解析位移训练标签**。损失仅为内部点的平衡残差均方。
- 验证：401 个未用于优化的均匀点；导数采用自动微分。导出 101 点用于显示，数字来自完整验证。
- 基准：同一问题的 100 个线性杆单元，三点 Gauss 荷载积分，固定两端。位移为分段线性，应力 / 应变为分段常数。验证恰在内部单元边界时取右侧单元，最右端取末单元。

## 2026-10-12 实测结果

| 指标 | 初始 PINN | 训练后 PINN | 100 单元 FEM |
| --- | ---: | ---: | ---: |
| 位移相对离散 L₂ 误差 | 57.7562% | 0.00211% | 0.00899% |
| 导数 / 应力相对离散 L₂ 误差 | 57.8509% | 0.00567% | 约 0.960% |
| 独立网格残差 RMS | 0.42049 | 1.6541 × 10⁻⁴ | 不直接比较强形式残差 |
| 独立网格最大残差绝对值 | 0.63726 | 5.7696 × 10⁻⁴ | 不直接比较 |
| 端点误差 | 0 | 0 | 0 |

完整配置、数值与计时保留在 [metrics.json](metrics.json)，实际轨迹在 [training-data.json](training-data.json)。训练脚本检查端点、位移误差、导数误差、独立残差及数值有限性后才输出成功结果。

这个比较只说明在当前光滑一维算例和所选配置中得到了哪些误差。FEM 导数是分段常值，PINN 导数来自光滑函数，自由度与训练成本也不同；**不能推导 PINN 比 FEM 普遍更准确或更快**。FEM 的强形式二阶残差不能用“单元内二阶导数为零”直接作公平比较，应检验弱形式或通量 / 整体平衡。

只跑一个种子、一个问题，没有做新材料、新载荷或新几何的分布外实验。采样验证不是全域严格证明；不是二维工程求解或工程部署验证。

## 20–30 秒动画分镜

| 阶段 | 画面 | 讲述 |
| --- | --- | --- |
| 0–4 秒 | 固定端、随机初始预测与解析参考 | “先定义问题；网络从一个不太对的函数开始。” |
| 4–8 秒 | 输入 ξ，输出 U，显示空间导数 / 残差 | “我们检查的不是曲线漂亮与否，而是它满足方程的程度。” |
| 8–20 秒 | 播放真实训练快照；误差与残差改变 | “优化参数，减小配点残差。解析曲线没有进入训练。” |
| 20–26 秒 | 停在末态，切到归一化应力并看数字 | “再用独立位置检查位移、应力和边界；本例只证明这个设定。” |

旧训练回放约 20 秒；GIF 额外停留首末帧，约 23 秒。新 Vibe Motion 视频为 36 秒，按建模逻辑分段呈现，作为当前 PPT 动画页的准备成片；HTML 原型仍用于交互查看曲线。

动画中的“迭代”是优化进度，**不是物理时间**。杆节点只沿轴向移动并放大显示，曲线高度不是弯曲形状。播放帧之间的插值只用于画面平滑，不是假造训练样本或误差。

## 复现

在项目根目录执行：

```powershell
python demo/train.py
python demo/render-animation.py
```

本机已用 Python 3.13.5、PyTorch 2.9.1+cpu、NumPy 2.1.3、Matplotlib 3.10.0 跑通；依赖范围见 [requirements.txt](requirements.txt)，不同版本可能影响细节。无需 OpenAI API 密钥。

`train.py` 输出 JSON、供离线浏览器读取的同源脚本以及指标；`render-animation.py` 输出 GIF 与静图。重新训练会更新这些派生产物，应同步重新渲染动画。

本机最初使用 NumPy 的 BLAS 运算时遇到 OpenMP 重复运行库冲突。现用基本数组规约及三对角消元避开该路径；未启用忽略库冲突的环境开关。不要把设置允许重复 OpenMP 库当作默认修复。
